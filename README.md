    # Project Title: Automated Smart Greenhouse Monitoring and Control System

## Project Overview
This project is a simulation-based system designed to automate and monitor greenhouse environments. It aims to reduce manual intervention by continuously tracking environmental conditions such as temperature, humidity, soil moisture, and light levels, and automatically controlling relevant actuators like fans, water pumps, and lights.

The system improves crop yield efficiency, minimizes resource wastage, and reduces human error in greenhouse management.

## Objectives
- Monitor real-time environmental parameters inside a greenhouse
- Automate irrigation, ventilation, and lighting systems
- Improve crop growth conditions through controlled environment
- Reduce dependency on manual monitoring and control

## Key Features
- Real-time sensor data simulation/processing
- Automated decision-making for environmental control
- Actuator control (fan, water pump, lights)
- Threshold-based system responses
- Modular and scalable design

## System Concept
The system follows a feedback control loop:
Sensors → Processing Unit → Decision Logic → Actuators → Environment Adjustment

## Technologies Used
- C++ (Core logic implementation)
- Simulation-based sensor inputs
- Control logic algorithms (threshold-based automation)

## Project Scope
This project is designed as a learning and demonstration system for embedded systems concepts, automation logic, and hardware-level control simulation.
